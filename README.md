# Последний фонарщик

Одиночная браузерная survival roguelite, вдохновлённая Vampire Survivors. Фонарщик с янтарным светом пробирается через заросший город вечной ночи: оружие атакует автоматически, враги оставляют опыт, а повышение уровня позволяет выбрать улучшение.

## Текущее состояние

Последняя настройка атмосферы: более плавное рассеивание тумана у огня и мягкое смешивание соседних пятен света. Густота вдали от источников сохранена; [проверка перехода](docs/evidence/stage-7/soft-transition/REPORT.md).

После завершения v1 добавлены шейдеры: динамический янтарный свет фонаря и уличных ламп, цветное освещение мотыльков, снарядов, искр и светящихся подборов; густой холодный туман рассеивается возле света, а неосвещённые враги едва видны. Огонь нерегулярно меняет яркость, радиус и тёплый оттенок света; у фонарей независимые фазы мерцания. Эффекты включены по умолчанию в забеге и мастерской боя. «Настройки → Свет и туман» отключает их и сохраняет выбор. На паузе/выборе уровня эффекты замирают; при системном уменьшении движения туман неподвижен и освещение не мерцает. HUD остаётся чётким; графическая мастерская показывает исходные атласы. Шейдеры требуют WebGL; Canvas сохраняет исходную графику. Это диффузное 2D-освещение без теней от препятствий. Для первоначальной версии эффектов с 300 врагами при 1280×720 получено 180,80 FPS в Chrome и 196,14 FPS в Edge на i5-14400F / RTX 5060 (60 с после прогрева). Текущая итерация — [густой туман и огонь](docs/evidence/stage-7/fire-fog/REPORT.md); первоначальные проверки — [свет и туман](docs/evidence/stage-7/REPORT.md).

Реализован полный забег на 600 секунд: четыре автоматических оружия, шесть пассивных предметов, шесть типов врагов, лечебный воск и магнит. Враги вводятся по расписанию волн; на 540-й секунде один раз появляется Сердце оранжереи. Босс предупреждает круговую волну шипов и места призыва ползунов, после потери половины здоровья атакует чаще. Победа требует живого героя, истечения 600 секунд и смерти босса. Если босс ещё жив на 10:00, бой и игровой таймер продолжаются; новые обычные враги, включая призывы, больше не появляются. Одновременная смерть героя и босса означает поражение.

«Мастерская боя» содержит отдельные 60-секундные испытания шести врагов, босса и трёх сборок. Рывки и снаряды имеют видимую подготовку; колокол показывает место будущего удара. Этап 6 завершён: процедурный звук, сохраняемые громкость/тряска, клавиатурные меню и проверенная статическая сборка. Звук включается после первого нажатия/клика; настройки доступны в верхней панели и паузе, не пропускают выбор улучшения и не возобновляют игру автоматически.

Исторический замер этапа 6 без новых шейдеров: 300 живых врагов, все четыре оружия, холст 1280×720: за 60 секунд после прогрева Chrome 155.0.8059.41 — 199,8 FPS / p95 5,1 мс; Edge 155.0.4283.45 — 199,8 FPS / p95 5,1 мс. Машина: Windows 11, i5-14400F, RTX 5060. Это отдельное испытание с повышенным HP/порогом XP, не проверка сложности обычного забега. Сырые интервалы, условия и ограничения — в [протоколе полировки](docs/evidence/stage-6/REPORT.md). [Архив статической версии](docs/evidence/stage-6/last-lantern-keeper-static.zip) содержит готовый сайт; публикация не выполнялась.

Участки города воспроизводятся по seed; трава и брусчатка разделены землёй, фонари/корни/скамьи/фрагменты оранжерей блокируют движение, растения и неглубокие лужи анимированы. Старт свободен, между препятствиями сохранены проходы. Есть пауза, поражение, результаты и чистый перезапуск. Экран результатов различает победу, поражение и завершение испытания мастерской.

Мастерская графики доступна отдельной кнопкой: восемь направлений героя, реакции/смерть, ползун, три материала и два набора по 47 переходных масок. Переключение из забега в мастерскую завершает текущую сессию.

Проверки записаны в [roadmap](ROADMAP.md), [протоколе графики](docs/evidence/stage-1/REPORT.md), [протоколе игрового цикла](docs/evidence/stage-2/REPORT.md), [протоколе карты](docs/evidence/stage-3/REPORT.md) и [протоколе контента](docs/evidence/stage-4/REPORT.md) и [протоколе полного забега](docs/evidence/stage-5/REPORT.md). Исходные рендеры Pixelmon доработаны покадровой пиксельной перерисовкой; производство ассетов не требуется при запуске игры.

Первая версия: ПК, забег на 10 минут, один герой, одна карта, шесть типов врагов, один босс, четыре оружия и шесть пассивных предметов. WASD или стрелки — движение, Esc — пауза. Документация и интерфейс на русском, промпты изображений на английском.

## Среда и команды

Проект: `C:\Users\1\Documents\GitHub\pixel-game`. Код и npm-команды запускать в Windows PowerShell из корня проекта; Pixelmon — в Ubuntu WSL. Браузерная игра не зависит от WSL или ComfyUI во время запуска.

```powershell
git rev-parse --show-toplevel
git status --short
node --version
npm --version
wsl -d Ubuntu -- bash -lc 'command -v pixelmon'
```

Git-корень должен указывать именно на `pixel-game`. На 2026-10-13 в папке уже есть отдельный пустой репозиторий; удалённый origin не настроен.

Команды доступны из корня проекта. Требуется Node.js 24+ (проверено на 25.1.0) и npm. Установка восстанавливает точные зависимости из lockfile:

```powershell
npm ci
npm run dev
npm run typecheck
npm run test
npm run build
npm run preview
npm run assets:check
```

Зафиксированы Phaser 3.90.0, TypeScript 5.9.3, Vite 8.3.4 и Vitest 4.1.11. Сервер разработки слушает [localhost:5173](http://127.0.0.1:5173/); `preview` показывает статическую сборку на [localhost:4173](http://127.0.0.1:4173/). На этой машине настроенное внешнее npm-зеркало не ответило, поэтому первоначальная установка выполнена с `--registry=https://registry.npmjs.org`, без изменения системной конфигурации.

Управление забегом: WASD/стрелки — движение, Esc — пауза, 1/2/3 или мышь — выбор улучшения. Потеря фокуса приостанавливает мир до явного продолжения; Esc не отменяет обязательный выбор. Новое оружие/предмет открывается на первом уровне. Оружия имеют пять уровней, предметы — три; предложения всегда различаются. При исчерпании улучшений остаются лечение и временные бонусы. Начальный радиус притяжения искр — 84 px; банка светляков увеличивает его, магнит притягивает все лежащие искры. Результаты показывают время, уровень, убийства, сборку и seed. Для повторяемой отладки открыть `/?debug=1&seed=20261014`; ускорения времени и команд выдачи XP в runtime нет. Диагностика карты и боя через `canvas.dataset` только читаемая и включается при `debug=1`. Неглубокая вода и растения декоративны, наземные существа обходят твёрдые препятствия. Сборка мастерской не переносится в обычный забег.

Управление мастерской: WASD/стрелки — движение, H — реакция на урон, K — смерть, R — восстановление, Esc — пауза. Вкладки показывают направления, маски и сложные стыки. При потере фокуса мастерская остаётся на паузе до Esc или R. Сцена имеет базовый размер 640×360 и целочисленный масштаб; для показа 2× требуется достаточно места для холста 1280×720 и интерфейса.

Дополнительная проверка принятой графики:

```powershell
node tools/check-assets.mjs --require-approved
node tools/check-tile-seams.mjs
```

Для Pixelmon сначала использовать проверки и инструкции из [ASSET_PIPELINE.md](docs/ASSET_PIPELINE.md). Команды генерации запускаются явно и могут включить локальный ComfyUI; не генерировать изображения при обычной проверке документов.

## Границы первой версии

В диалогах Tab/Shift+Tab и стрелки перемещают фокус, Enter/Space подтверждают кнопку. Ползунок громкости использует родное управление стрелками/Home/End; checkbox — Space. Esc закрывает настройки. При недоступном localStorage значения действуют до закрытия страницы, об этом сообщает UI; недоступный звук не мешает забегу. Системное prefers-reduced-motion отключает тряску и анимацию появления интерфейса.

Для повторения нагрузки открыть `/?debug=1` и выбрать «Нагрузочное испытание · 300 врагов». Автоматический замер на активной вкладке preview (в текущем протоколе порт 4174): `tools/run-stage6-performance.ps1 -Session stage6-chrome -Browser chrome`; перед ним открыть соответствующий браузер через Playwright CLI. Сценарии и точные условия перечислены в протоколе этапа 6. Обычный лимит врагов и баланс v1 этим режимом не меняются.

Без аккаунтов, серверной части, мультиплеера, мобильного управления и постоянной прогрессии. Звук и настройки входят в этап полировки. Графика и анимация проверяются до массового производства контента.

Источники: [Pixelmon](https://github.com/grymmjack/pixelmon), [анимации Phaser](https://docs.phaser.io/phaser/concepts/animations). Установленные параметры Pixelmon сверены с локальным исходным кодом; версия окружения записана в инструкции ассетов.
