# Плавный переход между туманом и светом

DONE, 2026-10-14, по запросу пользователя.

Рассеивание тумана теперь имеет широкую плавную кривую по расстоянию от огня. Убраны узкий дополнительный порог и выбор максимального рассеивания: перекрывающиеся источники совместно уменьшают остаточную плотность, без швов между пятнами. Затухание плавно достигает нуля на прежнем радиусе отсечения, поэтому внеэкранные источники не создают скачков. Параметр `fogFeather` находится в `src/data/atmosphere.ts`. Туман вдали остаётся густым; мерцание, плотность, палитра, симуляция и фильтрация пиксельных спрайтов сохранены.

Проверки: `npm run build` (включая typecheck и 14 атласов / 675 кадров / 94 маски), `npm test` (55 тестов / 9 файлов) прошли. [Chrome preview](visual-check.json): движение, оружия, смешивание света, слабые силуэты вне освещения, различимое предупреждение босса; ошибок браузера нет. [Короткая нагрузка](load-check.json): 5 с прогрева + 10,002 с, 300 живых врагов, один pipeline, 24 света и туман; 133,98 FPS, p95 10,1 мс. Машина та же, что в [исходном протоколе](../REPORT.md); полный 60-секундный замер заново не проводился.

Доказательства: [бой 2×](combat-2x.png), [босс 2×](boss-warning-2x.png), [запись 21,9 с / 1360×1120](soft-transition-2x.webm), [проверка декодирования](video-check.json), просмотренные кадры [середина](video-middle.png), [конец](video-late.png).
