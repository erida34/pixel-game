# Динамический свет и туман

Статус: DONE, 2026-10-14. Дополнение к завершённой v1 по запросу пользователя.

Этот протокол сохраняет доказательства первоначального варианта. Последующая настройка по отзыву пользователя — [густой туман и огонь](fire-fog/REPORT.md); её сборка и изображения сохранены отдельно.

## Результат

В забеге и мастерской боя действует настоящий GLSL PostFX-шейдер камеры. Фонарь следует за правой рукой героя во всех восьми направлениях; уличные лампы, включая источники за краем экрана, освещают землю янтарным светом. Мотыльки, иглы, вражеские снаряды, искры XP, лечебный воск, магнит, похититель и ядро босса дают локальные цветные пятна. Импульс фонаря и колокол добавляют короткую вспышку.

Туман состоит из трёхоктавного шума и второго слоя полос; привязан к миру, а не к экрану, медленно дрейфует и рассеивается у света. Холодный ambient сохраняет видимость земли. Яркие предупреждения атак, огни и XP защищены от затемнения. Исходный кадр семплируется без размытия, эффекты вычисляются в 640×360 и масштабируются вместе с игрой; HTML HUD/диалоги не проходят через шейдер.

«Настройки → Свет и туман» включено по умолчанию и сохраняет выбор. Старые version=1 настройки дополняются без потери громкости/тряски. Пауза и обязательный выбор уровня останавливают время эффектов. При prefers-reduced-motion туман неподвижен и освещение не мерцает. Canvas не подключает pipeline и сохраняет исходную игру.

Код: `src/rendering/AtmospherePipeline.ts`, `src/rendering/RunAtmosphere.ts`, `src/domain/lighting.ts`; параметры — `src/data/atmosphere.ts`. Ограниченный набор максимум 24 источника, дополнительно учитывается лимит uniforms GPU. Герой и уличные лампы приоритетнее декоративного XP. Шейдер и его render target освобождаются при отключении и смене сцены; менеджер камеры очищает main раньше shutdown, поэтому для очистки сохранена ссылка на камеру. RNG, боевые правила и атласы не изменены. API сверены с установленным Phaser 3.90.0 и [официальной документацией PostPipeline](https://docs.phaser.io/api-documentation/3.90.0/namespace/gameobjects-components-postpipeline).

## Проверки

- `npm run typecheck`, `npm test`, `npm run build` — проходят; [54 теста / 9 файлов](tests.json). Новые проверки: бюджет/приоритеты/стабильный выбор света, отсечение источников вне экрана у отрицательных координат, геометрия правой руки и миграция настройки.
- `node tools/check-assets.mjs --require-approved` — 14 атласов, 675 кадров, 94 маски. `node tools/check-tile-seams.mjs` — 239360 сравнений, 0 несовпадений.
- [Chrome smoke](chrome-smoke.json), [Edge smoke](edge-smoke.json): движение в восьми направлениях, offscreen lights, остановка времени и неизменный GPU framebuffer на паузе, визуальное отличие выключенного шейдера при том же времени/мире, сохранение отключения после reload, повторное включение, три чистых рестарта каждого браузера. Во всех стартах один выделенный pipeline / один keydown listener / 1037 объектов. Page errors, console errors/warnings и HTTP 4xx/5xx в этих проходах отсутствуют.
- [Настоящий уровень](upgrade-check.json) достигнут обычным боем на 13,383 с; время и источники неподвижны во время выбора, затем продолжают работу.
- [Canvas и reduced-motion](fallback-check.json): WebGL принудительно недоступен только в отдельной тестовой странице, игра выбирает Canvas, герой движется, Esc ставит на паузу, GL-ресурсов нет. Reduced-motion оставляет освещение, но выключает дрейф и мерцание.
- [Мастерская боя и босс](visual-check.json): движущиеся орбиты, огни похитителя, свет снарядов/подборов/искр, яркое ядро и кольцевое предупреждение босса. [Масштаб 1× и версии браузеров](scale-check.json).

Для проверки паузы сравниваются хеши ненулевого framebuffer через WebGL readPixels в requestAnimationFrame, вместе с неизменностью времени симуляции. В Edge PNG-захват браузера иногда слегка меняет оттенки одинакового кадра при композиции; непосредственно GPU-кадр остаётся одинаковым. Ошибка захвата не маскируется допуском к движению шейдера.

## Производительность

[Машина](machine.json): Windows 11 Pro 10.0.26200, Intel i5-14400F, NVIDIA RTX 5060, драйвер 32.0.16.1692; CPU/GPU/OS перепроверены в этой задаче. GPU backend — аппаратный ANGLE NVIDIA D3D11. Viewport 1360×1120, базовый canvas 640×360, отображение 1280×720, свет/туман включены, громкость 45%, тряска выключена.

Одинаковое с этапом 6 отдельное нагрузочное испытание: 300 живых врагов всех шести типов с реальным AI/столкновениями/уроном и пополнением после смертей; все четыре оружия 5 уровня. HP и порог XP увеличены для непрерывного замера, обычные волны/босс выключены. После 10 с прогрева фиксируются первые 60 с requestAnimationFrame с новым Phaser frameSerial; движение WASD по 5 с, выборки состояния каждые 250 мс. Другая вкладка/браузер во время измерения не активировались.

Цель среднего ≥60 FPS / p95 ≤16,67 мс достигнута. Во всех выборках свет включён, один проход и один выделенный pipeline. Игровое время продвинулось на 59,92 / 59,97 с между крайними 250-мс выборками. Ограничение источников не меняет симуляцию.

Сырые интервалы и выборки: [Chrome](chrome-performance.json), [Edge](edge-performance.json); [Chrome окружение](chrome-performance-environment.json), [Edge окружение](edge-performance-environment.json); [сводка и точные версии](summary.json). Это измерение на машине пользователя, а не обещание FPS на другом оборудовании и не оценка сложности обычного забега.

Повторение: preview на порту 4175, открыть соответствующий браузер через установленный Playwright CLI, затем `tools/run-stage7-performance.ps1 -Session shader-chrome -Browser chrome` или сессия shader-edge / browser edge. Скрипт использует общий метод segment/finish этапа 6. Браузер должен оставаться передним планом весь замер.

## Сборка и ограничения

[Статический сайт с шейдерами](last-lantern-keeper-shaders-static.zip) содержит 32 файла из dist; [SHA256 файлов и архива](build.json). Подавать через обычный HTTP static server. Архив этапа 6 сохранён как историческое доказательство прежней сборки.

Освещение диффузное 2D: без отбрасываемых теней, normal maps, перекрытия света стенами и объёмного рассеяния. При заполненном бюджете низкоприоритетные источники остаются яркими в спрайте, но перестают освещать землю. Экранные оттенки после шейдера выходят за ENDESGA-32; палитра исходных атласов сохранена. Крупный JS bundle: 1274,78 KB / 345,63 KB gzip, прежнее предупреждение Vite остаётся. Полный 600-секундный забег повторно не проходился; правила покрыты имеющимися и текущими тестами, визуальные изменения проверены отдельно. Коммит, push и публикация не выполнялись.
