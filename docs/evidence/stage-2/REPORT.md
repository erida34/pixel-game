# Этап 2 — игровой цикл

Дата: 2026-10-13. Проверяет агент в локальном Chromium. Коммит, push и публикация не выполняются.

## Реализация

Меню → 180-секундный забег → опыт/выбор → продолжение → результаты → чистый новый забег. Фонарщик и ползуны используют принятые атласы этапа 1. Камера следует за героем по бесконечно повторяющемуся фиксированному двору. Янтарный фонарь автоматически наносит круговой урон, ползуны преследуют героя и причиняют контактный урон с неуязвимостью 0,8 с. Смерть ползуна даёт одну искру XP; притяжение, подбор и очередь нескольких повышений уровня работают в чистой модели.

Доступны фонарь (5 уровней), линза и сапоги (по 3). Предложения различаются и исключают максимальные уровни, свободные места заполняются лечением/временными бонусами. Мир и эффекты замирают при выборе и паузе; Esc не отменяет обязательный выбор. Потеря фокуса требует явного продолжения. Результаты содержат исход, время, уровень, убийства, seed и копию сборки. Итог `prototype_complete` не называется победой v1.

Баланс хранится в `src/data/prototype.ts`, типы — `src/domain/run.ts`, правила — `src/systems/runSimulation.ts`. Пространственные запросы используют hash по клеткам, записи врагов/XP и отображаемые спрайты переиспользуются. Очистка сцены снимает обработчики и сбрасывает UI/ввод. Runtime не требует WSL и не меняет provenance принятых атласов. Новые эффекты — собственные простые формы в коде, как описано в ASSET_PIPELINE.

## Проверки

Windows, Node.js 25.1.0, npm 11.11.1, Chromium 155.0.8059.40 / WebGL. Холст 640×360, показ 2× при viewport 1360×1120. Производительность в рамках этапа 2 не измерялась. Сервер разработки этой проверки — порт 5174, отдельный preview — 4180.

- `npm run typecheck` — успешно.
- `npm test` — 3 файла, 15 тестов. Проверяются нормализация движения, интервал контактного урона в толпе, один hit за импульс, однократность XP/подбора, несколько уровней, пауза/выбор, максимальные уровни и fallback, временные бонусы, заполнение XP-пула, приоритет поражения на границе таймера, копия результата, чистый рестарт, seed 0, ограничение накопителя и отрицательные клетки spatial hash; сохранены тесты движения/кадров/тайлов этапа 1.
- `npm run build` — успешно; основной JS около 1,23 MB / 330 KB gzip. Предупреждение Vite о размере сохраняется до оптимизации этапа 6.
- `node tools/check-assets.mjs --require-approved` — 5 атласов / 287 кадров / 94 маски, всё approved.
- `node tools/check-tile-seams.mjs` — 239 360 сравнений, 0 несовпадений.
- [Браузерный smoke](browser-check.json) — восемь направлений/остановка, Esc замораживает время/движение/кадр, обработчик blur ставит паузу, focus её не снимает. Реальный бой даёт первое повышение на 13,38 с; три разные карточки, Esc не обходит выбор, клик применяет улучшение один раз. Мастерская и возврат к новому забегу работают. Ошибок и предупреждений нет. События blur/focus здесь посланы браузерному обработчику; это отдельно от проверки переключения вкладок.
- [Полный забег](full-run.json) — 180 секунд настоящего игрового времени, seed 20261013, 193 убийства, уровень 14, 80 HP; фонарь 5, линза 3, сапоги 3. Пять отрезков по 40/40/40/40/22 секунды реального времени, с явными паузами между отрезками. Время не ускорялось, XP/HP не подменялись; управление только клавиатурой/мышью. Файлы отрезков перечислены в JSON, проверена непрерывность игрового времени. Выборы мышью и клавиатурой, максимальные уровни и лечение после заполнения сборки подтверждены. Результат — `prototype_complete`.
- [Перезапуски и настоящий blur/focus](restart-focus-check.json) — после поражения восстановлены 80 HP, уровень 1, нулевые время/XP/убийства, пустые пулы и начальный фонарь. Три последовательных старта имеют одинаковые 692 объекта сцены. Реальное переключение на другую вкладку после отключения эмуляции фокуса CDP ставит паузу; возврат сохраняет её и время 0,05 с. Синхронизировано диагностическое поле phase, чтобы его можно было прочитать и без следующего кадра рендера. Ошибок нет.
- [Статическая сборка](preview-check.json) — загрузка ассетов из `dist`, движение камеры, реальный бой/XP, три карточки, выбор клавишей 1, пауза, мастерская и чистый повторный старт. Ошибок консоли, предупреждений и HTTP нет.
- [Контактное поражение](death-segment-1.json) — 50,25 с, 28 убийств, уровень 6, фонарь 1 / сапоги 3. Урон от врагов доводит HP до нуля; время после смерти не меняется, кадры `00`…`05` проходят перед результатами. Последующий новый забег также проверен в [следующем отрезке](death-segment-2.json).

## Ограничения

Поверхность фиксирована и не зависит от seed; генератор участков, препятствия и окружение — этап 3. Один тип врага и одно оружие; остальной контент — этап 4. Баланс предварительный: текущий прототип допускает выживание с небольшими перемещениями при последовательном усилении фонаря; окончательная сложность проверяется на этапе полного забега. Производительность с 300 врагами и Chrome/Edge на машине пользователя относятся к этапу 6. GPU и новая генерация на этом этапе не запускались.

Следующая задача — этап 3 из PROMPTS: процедурная карта по seed с участками, препятствиями и деталями окружения.
