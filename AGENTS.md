# AGENTS.md — инструкции агенту проекта

## Рабочая область и безопасность

Эта папка — рабочая область игры «Последний фонарщик». Используй уже предоставленный контекст запуска; не перечитывай личные SOUL.md, USER.md и память без необходимости. Если BOOTSTRAP.md появится, сначала прочитай его; удаление выполняй только в пределах явного разрешения пользователя.

- Работай только с файлами игры. Не раскрывай приватные данные и не копируй содержимое личных файлов в документы или коммиты.
- Перед Git-операциями проверь `git rev-parse --show-toplevel`: ожидается корень `pixel-game`. Каталог раньше наследовал репозиторий `C:\Users\1`; не выполняй команды против родительского репозитория.
- Перед изменениями проверь `git status --short`; сохраняй чужие изменения. Не откатывай их и не запускай разрушительные команды без разрешения. Предпочитай восстановимое удаление.
- Публикация, push, отправка сообщений и другие внешние действия требуют явной авторизации пользователя. Локальная реализация согласованной задачи разрешена.
- Не записывай секреты в журнал. Память вне проекта изменяй только по явному запросу пользователя. История разработки хранится в roadmap и проверках этапа.

## Вход в проект

1. Прочитай README.md и docs/GAME_DESIGN.md.
2. Прочитай ROADMAP.md; выбери первый незавершённый этап, зависимости которого имеют статус DONE.
3. Прочитай docs/ART_DIRECTION.md и документы текущего этапа: docs/ARCHITECTURE.md, docs/ASSET_PIPELINE.md.
4. Используй задание из PROMPTS.md. Если пользователь задаёт другую ограниченную задачу, выполняй её и отражай влияние на roadmap.

Разрешай вопросы о существующих файлах и окружении через исследование. Существенные изменения согласованной концепции, объёма и требований уточняй у пользователя; обычные решения внутри этапа принимай самостоятельно.

## Работа над этапом

- Выполняй один проверяемый этап за раз. Перед работой отметь IN_PROGRESS. Для BLOCKED укажи конкретную причину и действие, которое разблокирует работу; продолжай независимые проверки.
- Разделяй игровую логику, отображение, типизированные данные контента и производство ассетов. Следуй архитектуре; параметры баланса не зашивай в обработчики сцен.
- Не добавляй сервер, аккаунты, мобильное управление или постоянную прогрессию в v1.
- Проверяй действующие API по первичной документации. Сохраняй точные зависимости и lockfile при инициализации; не обновляй их без причины.
- Не запускай массовую генерацию до принятия героя, одного врага и переходов земли. Используй установленный Pixelmon в WSL для базовой графики.
- Статичный спрайт, поворот одной картинки и пульсация масштаба не заменяют покадровую ходьбу. Временные ассеты отмечай как placeholder в манифесте и roadmap.
- У каждого принятого ассета сохраняй промпт, seed, параметры, версию инструмента, происхождение и сведения о доработке. Локальные абсолютные пути и модели не включай в runtime игры.

## Проверки и завершение

- Для кода выполняй доступные typecheck, тесты затронутой логики и build. Перечень npm-команд в README относится к будущему этапу 1, до него проверяй документацию.
- Проверяй игровое поведение в браузере. Для графики сохраняй скриншоты и короткую запись движения; для производительности записывай машину, браузер, разрешение и измерения.
- Генерация PNG или успешная сборка сами по себе не означают готовность этапа. DONE ставь только после всех его критериев.
- В ROADMAP.md обновляй статус, выполненные проверки, ссылки на доказательства, известные проблемы и следующую задачу. Не обещай несуществующие команды или артефакты.
- В конце кратко сообщай, что изменилось, что проверено и какие ограничения остаются. Не создавай коммит и не публикуй проект без задачи, которая это разрешает.

## Поддержание документов

Описание игры — источник истины для механик; ART_DIRECTION — для внешнего вида; ARCHITECTURE — для интерфейсов; ASSET_PIPELINE — для производства; ROADMAP — для состояния. При изменении требования обновляй связанные документы вместе. Сохраняй русский текст в UTF-8, промпты генерации — на английском.

Эти инструкции относятся к проекту. Они не создают фоновые проверки почты, календаря или автоматические heartbeat-задачи.
